Override context name using a Tomcat context descriptor
-------------------------------------------------------

1. Go to Tomcat’s configuration directory
-----------------------------------------
    $ $CATALINA_BASE/conf/Catalina/localhost/

2. Create a file named after your desired context
-------------------------------------------------
    <context-name>.xml

3. Add this content
-------------------
    <Context
        docBase="<path-to-the-war-file>" <!-- ex: /home/springboot/<file-name>.war -->
        reloadable="true" />

4. Restart Tomcat
